# dune-boardgame

A Dune-inspired digital boardgame prototype built with React + Vite.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deploy to Vercel

1. Import the repository into Vercel.
2. Set the framework preset to Vite.
3. Keep the default build settings.
4. Deploy.

## Notes

This is a fan-made strategy prototype inspired by the Avalon Hill Dune boardgame, not an official licensed product.
